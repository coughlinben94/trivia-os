How the traversal actually works

Plane state is derived purely from one integer, depthIndex (bumped once per round boundary) — planes are rebuilt from that number on every advance, never accumulated transform-on- transform, per the "idempotent, survives a mid-show refresh" note from one of the two Fable reviews. On advance: planeNear scales to ~2.6x and fades out past the frame edges (the "walked past it" beat), planeMid promotes into the near slot (scale ~1.6x → 1x, same transform/opacity transition), and a new mid plane fades in behind at ~0.55x, desaturated and blurred (atmospheric perspective, static filter set at spawn — never animated, per the GPU law). The old exited plane is removed from the DOM only after its own transition finishes.

Recycling (every 3rd advance in this proof)

Instead of unique headstone art per round, a recycled plane mirrors (scaleX(-1)), re-rolls its random headstone/cross layout (the same Math.random() placement the shipped theme already uses for fog/bats — no new mechanism), and shifts one degree darker/deeper into the palette per lap. This is deliberately visible in this proof (the legend calls out "(recycled)") so you can judge whether it actually reads as fresh vs. as a repeat — that judgment call is yours, not something to self-certify.

The filter-handoff snag, solved

A promoted plane's blur/saturation can't animate (GPU law is explicit: filter must be static). This proof swaps each plane's filter value in one step exactly when its promotion transition starts — imperceptible in motion, unlike animating the filter itself which would violate the transform/opacity-only rule.

What this is NOT proving yet

Only 2 cycling planes (near + mid), not the full 3-cycling-plus-fixed-anchor stack a shipped version might want. No mid-round "surge" layered on top yet (fog/bats spike) — this proof is traversal only, to keep it legible. Both Fable reviews were explicit: prove traversal + recycling on 2 flagship themes with existing assets before drawing one new art layer — this is exactly that, zero new art beyond what the shipped Halloween theme already owns (headstones, cross, fog, bats, moon).
