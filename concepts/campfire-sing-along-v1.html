Composition — safe-zone baked in, not rescued

Every figurative element (treeline, both chairs, flame, logs, reflection, sand path) sits with its top edge at or below stage-y 58% at the highest (treeline) — the entire pictorial scene lives in the bottom ~42% of the frame. The question safe-area floor is y72%; the reflection (the one element that came closest to it) has its topmost, brightest ellipse box starting at 72.6% — 0.1pp of deliberate extra clearance beyond the floor itself, by construction — so this file ships with no scrim, no dimming layer, and no rescue mechanism of any kind for the reflection. Embers are capped to fade to opacity 0 by the time their rise would cross y72%, for the same reason. Stars and the shooting star are the only elements permitted inside the safe-area band, per this task's own explicit allowance for quiet twinkling motion there.

Radial-gradient margin math (every glow/pool/reflection layer)

#flameGlow box 26%×26% at (37%,72%): ellipse 40% 55% at 50% 78% → x margin 10% each side (PASS), y top margin 23% (PASS), bottom overflows past ground-anchor exemption. #flameCore box 12%×12% at (44%,80%): ellipse 38% 40% at 50% 65% → x margin 12% (PASS), y top margin 25% (PASS), bottom exempt. #groundPool box 40%×12% at (30%,88%): ellipse 40% 60% at 50% 85% → x margin 10% (PASS), y top margin 25% (PASS), bottom exempt (box bottom = stage 100%, the screen edge itself). Every .refl ellipse uses the identical internal gradient ellipse 40% 40% at 50% 50% → 10% margin on every axis (PASS) regardless of the outer box's size/position, since the percentage math is self-contained per box. Every .ember/.star dot's own tiny radial gradient is ellipse 42% 42% at 50% 50% → 8% margin each axis (PASS at the threshold). No box-shadow is used anywhere in this file for a glow effect.

Blur — graduated by depth, not a flat floor value

Foreground silhouettes (treeline, chairs, logs, flame, sand path): 1.5px — the established floor, applied uniformly to keep one soft rendering register across every hand-drawn edge in the scene (avoids the sharp-vector-next-to-soft-glow mismatch this project has flagged before). Embers/stars: 1.5–2px. Ambient glow/pool/core/reflection layers: 3–6px, deepest on the ground pool. No element in this file is fully unblurred.

Motion inventory (GPU-only: transform/opacity, static filter only)

  • Flame — flameFlicker, 2.6s, scaleX/scaleY + opacity, transform-origin 50% 100%.
  • Bloom glow / hot core — glowPulse/corePulse, 2.6s, same phase as flame, opacity only.
  • Ground light pool — poolPulse, 2.6s, 0.55s delay — lags the flame rather than strobing in sync.
  • Embers (×6) — emberRise, 4.4–7.2s, negative delays, translate + opacity, capped to fade out before crossing the 72% floor.
  • Stars (×24) — starTwinkle, 3.2–6.6s irregular periods, negative delays, opacity only, alpha range 0.22–0.55 per themes.md's star-field convention.
  • Shooting star — meteorStreak, 34s cycle, ~1s visible window, translate + opacity, path confined to y6–21% (upper sky).
