The detent: world-02 split the travel at 0/11/34/52/74/88/100 with a different timing function per segment — six chained curves pretending to be one, and it read as chop. Here X has two stops under one asymmetric ease-out and Y has three (the arc's mid peak at 42%, ease-in-out both halves, zero slope at the crest from both sides). Every layer shares the same two curves and the same 1.2 s; only amplitude differs. Wrap modulo still lands in the same task as class removal — one paint. And the world never stops: each layer also drifts continuously (linear, prime loop durations 331/337/347 s), so the detent is a surge over ever-present motion instead of a lurch out of stillness, and the question exit rides on the move instead of preceding it.

The text: binary-search measure-to-fit (canvas measureText, real glyphs, behind fonts.ready) picks the largest size at which the question wraps into 60cqw × 38.8cqh at ≤4 lines. The block centre-anchors at 50cqh, so worst case it spans exactly 28–72cqh. The scrim is placed from the block's measured rect every time the question changes or the stage resizes.
